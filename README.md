<details>
<summary>⚙️ <b>Enable the animations (2-minute setup)</b></summary>

<br/>

The snake game and 3D contribution graph above are generated by GitHub Actions running in your **profile repo** (the special repo named exactly `Lakshya-Purohit/Lakshya-Purohit`). They won't render until you add these workflows once.

**1. Snake animation** — create `.github/workflows/snake.yml`:

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:
  push:
    branches: [main]

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        id: snake
        with:
          github_user_name: Lakshya-Purohit
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

**2. 3D contribution graph** — create `.github/workflows/3d-contrib.yml`:

```yaml
name: 3D Contribution Graph
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: yoshi389111/github-profile-3d-contrib@0.7.1
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          USERNAME: Lakshya-Purohit
      - name: Commit & push
        run: |
          git config user.name github-actions
          git config user.email github-actions@github.com
          git add -f profile-3d-contrib
          git commit -m "generate 3d contrib graph" || echo "no changes"
          git push
```

**3.** Commit both files to your profile repo's `main` branch, then go to the **Actions** tab and run each workflow once manually (`Run workflow` button). After that they auto-refresh on schedule, and the images already linked in this README above will start showing up.

</details>
